          Check, then pay

          Send USDC on Arc from your own browser wallet, such as MetaMask. This site never sees your keys and never signs anything. Your wallet shows the payment before you approve it.

            Save this check on Arc

            Write this result to the RiskAttestation contract on Arc from your own wallet, so anyone can see who checked this address, when, and what the score was. It costs a small fee in USDC.

            How it works

            • Read-only. The check only reads public data from Etherscan, GoPlus, DexScreener, and Arc's RPC nodes. It never asks for a private key.
            • Built for Arc. On Arc, USDC is the native coin. Every USDC move is read from Arc's system Transfer logs and counted once, at 18 decimals. Every address is checked against the USDC and EURC blocklists.
            • Explainable. No black box: each point in the score comes from a public rule, with its source.
            • For AI agents too. The same check is an MCP tool. Agents that pay in USDC can call score_risk with chain: "arc" before they send.

            A low score is not a promise of safety. It means the data we could check showed no red flags. Not financial advice. Source code
